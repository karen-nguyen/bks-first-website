Everything above the first "#" line is ignored, so this is just a note to you.

HOW TO ADD A POST
  1. Copy one of the posts below.
  2. Paste it at the TOP of this file (newest first is nicest, but the site
     sorts by date anyway, so it does not really matter).
  3. Change the words. Save. Push.

EVERY LINE IS OPTIONAL EXCEPT THE "#" TITLE LINE.

  # Title of the post          <- starts a new post. Required.
  date: 2026-04-18             <- year-month-day. Used for sorting.
  team: Roboboat               <- Solar Car, Roboboat, Robotics, M.A.R.S., Drones, or Club
  result: 3rd of 18 teams      <- shows as a red result line. Leave out if not a competition.
  author: Kris N.
  photo: <link> | caption      <- the big photo at the top of the post
  link: https://...            <- optional button at the end of the post
  linktext: Full results

  Then leave a blank line and just type. Each blank line starts a
  new paragraph.

  photos:                      <- a gallery. One link per line.
  <link> | optional caption
  <link>

PHOTO LINKS
  Google Drive: right-click the photo in Drive, Share, "Anyone with the link,"
  Copy link, paste it here. That is the easiest way.
  Google Photos: open the photo, right-click it, "Copy image address."
  (The plain Google Photos share link will NOT work - the site will tell you so.)
  Or drop a file in website/assets/photos/ and write assets/photos/name.jpg
